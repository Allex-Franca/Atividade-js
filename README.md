# Exercicios de JavaScript com DOM

## Como fazer

1. Faca um **fork** deste repositorio clicando no botao "Fork" no canto superior direito
2. Clone o seu fork para sua maquina
3. Abra o arquivo `index.html` no navegador para ver os exercicios
4. Edite o arquivo `script.js` para resolver cada exercicio
5. Faca commit e push das suas solucoes

## Exercicios

| # | Exercicio | O que voce vai aprender |
|---|-----------|------------------------|
| 1 | Mudar texto | `textContent` |
| 2 | Mudar cor | `style.color` |
| 3 | Esconder elemento | `style.display` |
| 4 | Adicionar item na lista | `createElement`, `appendChild` |
| 5 | Mudar cor de fundo | `style.backgroundColor` |
| 6 | Contador | Ler e atualizar valores |
| 7 | Capturar input | `.value` |
| 8 | Adicionar classe | `classList.add` |
| 9 | Remover item da lista | `removeChild` |
| 10 | Trocar imagem | `.src` |

## Dicas

- Use `document.getElementById("id")` para selecionar elementos
- Use `.addEventListener("click", function)` para detectar cliques
- Abra o console do navegador (F12) para ver erros
- Cada exercicio tem dicas no proprio arquivo `script.js`
